# SQL Data Analysis Portfolio

This repository contains my SQL analytical projects based on the Northwind database.

During the past months I practiced solving real business-style analytical problems using SQL.  
The focus of these projects is exploring business data and extracting insights.

## Topics covered

- Customer behavior analysis
- Order structure and sales metrics
- Delivery cost analysis
- Impact of discounts on sales
- Customer segmentation
- Business metrics exploration

## SQL techniques used

- JOIN
- CTE (Common Table Expressions)
- Window Functions
- Aggregations
- Subqueries
- Analytical queries

## Goal of the repository

The goal of these projects is to practice analytical thinking and data analysis using SQL on business data.

This portfolio demonstrates my ability to:
- build analytical datasets
- analyze business metrics
- explore patterns in data
- solve analytical problems with SQL
